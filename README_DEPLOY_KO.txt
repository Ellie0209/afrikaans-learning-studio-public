Afrikaans Studio · South Africa-first v9

이번 버전은 Dutch 느낌의 일반 유럽형/3D 캐릭터 디자인을 제거하고 남아공 중심 디자인으로 재구성한 최종본입니다.

주요 변경
- 남아공 국기 컬러를 이용한 헤더/사이드바/레벨 UI
- Suid-Afrika · Kaapstad · Tafelberg · fynbos · Karoo · Weskus 아이덴티티 스트립
- 3D Character 테마 제거
- Cape Coast / South Africa Journey 두 남아공 테마로 변경
- Muizenberg/케이프 해안과 Table Mountain 이미지를 학습 화면에 사용
- Dutch/네덜란드 비교 문구를 화면 콘텐츠에서 제거하고 South African Afrikaans 중심으로 재작성
- PWA 아이콘을 남아공 컬러 기반으로 변경
- Service Worker 캐시 v9로 갱신
- A0-C2 56개 레슨, 듣기, 퀴즈, Writing Lab, 문법, 문화, 진행기록 기능 유지

배포
1. ZIP을 압축 해제합니다.
2. GitHub 저장소 루트에 파일을 업로드해 같은 이름의 기존 파일을 교체합니다.
3. Commit changes를 누르면 Vercel이 자동 재배포합니다.
